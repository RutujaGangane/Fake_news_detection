# Fake_news_detection
"Mtech_mini_project"

Dataset used for the project : LIAR dataset

Project PPT is also present in this repository.

The widespread dissemination of fake news poses a significant threat to public trust, decision
making, and social stability. This project focuses on detecting fake news using advanced lan
guage models—specifically BERT (Bidirectional Encoder Representations from Transformers)
and RoBERTa (Robustly Optimized BERT Approach). By leveraging the LIAR dataset, we pre
process textual data and apply transformer-based models to distinguish between real and fake
news. The BERT and RoBERTa models are evaluated using accuracy, precision, recall, and
F1-score, with RoBERTa achieving slightly higher accuracy (64%) compared to BERT (63%).
These results highlight the effectiveness of transformer-based approaches for text classification
tasks in fake news detection and demonstrate the value of fine-tuned pretrained models in im
proving performance over traditional methods. The study also emphasizes the importance of
tokenizer alignment and careful data preprocessing in enhancing model effectiveness.
